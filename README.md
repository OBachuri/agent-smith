## Instructions

###  Requirement

Docker, uv and deno must be installed in advance.

Docker install - https://docs.docker.com/engine/install/

Install uv: 
```
pip install uv
# or
curl -LsSf https://astral.sh/uv/install.sh | sh
# check 
uv --version
```

Install deno:
```
curl -fsSL https://deno.land/install.sh | sh
```
